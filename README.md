# 📊 Customer Demographics Study

An end-to-end **Data Analytics project** focused on understanding customer demographics, purchasing behavior, income patterns, spending behavior, and preferred product categories using **Python, SQL Server, and Power BI**.

---

## 📌 Project Overview

The Customer Demographics Study analyzes customer-level demographic and behavioral data to identify meaningful patterns in customer income, spending, purchase frequency, gender distribution, age groups, and product preferences.

The project follows a complete analytics workflow:

**Data Cleaning → SQL Analysis → Power BI Visualization → Business Insights**

The final outcome is an interactive **Power BI dashboard** supported by Python data cleaning and SQL-based analysis.

---

## 🎯 Project Objectives

- Clean and validate the customer dataset.
- Analyze the overall customer population.
- Understand customer demographics by age and gender.
- Compare average income across demographic groups.
- Analyze purchase frequency across age groups.
- Identify preferred product categories.
- Analyze the relationship between income and spending score.
- Build an interactive Power BI dashboard.
- Present findings through a professional report and presentation.
